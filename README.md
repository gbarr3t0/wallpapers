# 🖼️ Linux Wallpapers Megapack

A personal, curated collection of **1,300+ high-resolution desktop wallpapers** (`1920x1080` and above) gathered for Linux ricing (Hyprland, Sway, Caelestia Shell, GNOME, KDE, etc.).

All images were filtered to remove low-resolution files, vertical mobile crops, and exact duplicates, then optimized for fast loading.

---

## ✨ Categories & Themes

- **Cozy & Pixel Art:** Snowy biomes, voxel landscapes, rain scenes, medieval fantasy, and warm pixel art.
- **Color Palettes:** Curated wallpapers matching **Rosé Pine**, **Catppuccin**, **Nord**, **Gruvbox**, and **Everforest**.
- **Anime & Manga:** Stylized scenes, recolored manga panels, and minimalist character art.
- **Landscapes & Minimal:** Nature photography, space, digital illustrations, and clean vectors.

---

## 🚀 Quick Clone

Download the entire collection directly into your wallpapers directory:

```bash
git clone --depth 1 https://github.com ~/wallpapers
```
